Dine

Вьюер и экспортёр миров Minecraft. Открываешь папку сохранения — видишь 3D-сцену или 2D-карту. Экспортируешь в GLB или OBJ для Blender.

![screenshot_placeholder](https://via.placeholder.com/800x450/1a1a2e/ffffff?text=Dine+Screenshot)

Скачать

Скачай последний релиз из [Releases](https://github.com/rezervkant-cmd/dine/releases) и запусти `dine`.

При первом запуске сам найдёт `client.jar`. Если нет — скачает с Mojang.

Запуск

```bash
./dine                          # GUI
./dine /path/to/world           # сразу открыть мир
./dine /path/to/world --mods /path/to/mods
```

Управление

Действие	Клавиша	
Вращение	ПКМ + движение	
Орбита	ЛКМ + движение	
Панорама	СКМ или ЛКМ + Shift	
Лететь	W A S D / Space Q	
Ускорение	Shift	
Масштаб	Колёсико	

Что умеет

- Миры Minecraft 1.12+ (Overworld, Nether, End, модовые измерения)
- Моды: Fabric, Forge, NeoForge
- Три режима текстур: блоки / средние цвета / плоские цвета
- Фильтры: убрать воду, декор, барьеры, листву
- 2D-карта с выделением области
- Экспорт: GLB (один файл) или OBJ + PNG (для MCprep)
